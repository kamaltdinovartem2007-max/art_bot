# 🖼 Art Quiz Bot — инструкция по запуску

## Структура папки

```
art_quiz_bot/
├── bot.py              ← основной код бота
├── artworks.json       ← твои произведения (редактируй)
├── requirements.txt    ← зависимости
└── images/             ← папка с картинками (создай сам)
    ├── mona_lisa.jpg
    ├── starry_night.jpg
    └── ...
```

---

## 1. Установка

```bash
pip install -r requirements.txt
```

---

## 2. Получить токен бота

1. Открой Telegram → напиши @BotFather
2. `/newbot` → придумай имя и username
3. Скопируй токен вида `7123456789:AAH...`

---

## 3. Вставить токен

Открой `bot.py` и замени строку:
```python
BOT_TOKEN = os.getenv("BOT_TOKEN", "YOUR_BOT_TOKEN_HERE")
```
на:
```python
BOT_TOKEN = "7123456789:AAH..."   # твой токен
```

Или запусти через переменную окружения:
```bash
BOT_TOKEN="7123456789:AAH..." python bot.py
```

---

## 4. Добавить свои произведения

Отредактируй `artworks.json`. Для каждого произведения:

```json
{
  "title": "Название произведения",
  "author": "Автор",
  "image": "images/имя_файла.jpg",
  "title_aliases": ["Название", "альтернативное название", "english name"],
  "author_aliases": ["Автор", "другое написание", "English Name"]
}
```

- `title_aliases` — все варианты написания названия, которые бот примет как верный ответ
- `author_aliases` — все варианты написания имени автора
- `image` — путь к файлу картинки (положи в папку `images/`)

---

## 5. Запуск

```bash
python bot.py
```

---

## Как пользоваться ботом

| Команда | Действие |
|---------|----------|
| `/start` | Начать викторину (5 случайных произведений) |
| `/stop`  | Остановить викторину |

**Формат ответа:** `Название — Автор`

Примеры принимаемых ответов:
- `Мона Лиза — Да Винчи`
- `The Starry Night — Van Gogh`
- `Давид — Микеланджело`

Бот принимает любые варианты из `title_aliases` и `author_aliases`, регистр не важен.
